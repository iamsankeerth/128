# Your practice answers

When **GitHub sync** is enabled in the tracker app, your selected answers and timer progress for each study day are saved here as JSON.

- **File format:** `YYYY-MM-DD.json`
- **Updated:** Automatically after you answer questions (debounced ~2.5s)
- **Requires:** A GitHub personal access token with `repo` scope (configured once in the app)

Answer keys (correct answers) are posted separately in `answers/` by the daily GitHub Actions workflow.
